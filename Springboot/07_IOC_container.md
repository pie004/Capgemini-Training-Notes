## What is IOC?
IOC stands for Inversion of Control.
AT first we used to create java objects by ourselves, but now we will let the framework create objects for us, and we will use those objects to do our work, which means we have externalised the control of object creation. This is called Inversion of Control.

## What is IOC Container?
IOC Container is a container that creates and manages the lifecycle of objects in a Spring application. It is responsible for creating objects, wiring them together, configuring them, and managing their lifecycle. The IOC Container is also responsible for injecting dependencies into objects.
